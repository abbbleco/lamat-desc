Lamat | Complete Dating & Social Networking Platform

Lamat is a full-featured dating and social networking script built on Laravel 11 and flutter. It includes a powerful REST API backend with 150+ endpoints, an admin dashboard, real-time messaging, voice and video calls, and a complete monetization system. Designed to launch all in one social dating solution.

  • Smart matching algorithm with mutual match detection and instant notifications
  • Location-based discovery with adjustable search radius (Haversine distance calculation)
  • Gender, age range, and preference filters
  • Global match toggle for worldwide discovery
  • Boost priority in swipes - boosted users appear first in discovery
  • Already-swiped, blocked, and disliked users are automatically filtered out
